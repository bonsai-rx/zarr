# Bonsai.Zarr

`Bonsai.Zarr` provides operators for logging numeric data streams to Zarr version 3 stores in the [Bonsai visual reactive programming language](https://bonsai-rx.org). The stores can be read with any Zarr reader, such as `zarr-python` or `xarray`.

## How to Use

To use `Bonsai.Zarr` for visual reactive programming, install this package using the [Bonsai package manager](https://bonsai-rx.org/docs/articles/packages.html).

## Additional Documentation

For additional documentation and examples, refer to the [official Bonsai.Zarr documentation](https://bonsai-rx.org/zarr).
